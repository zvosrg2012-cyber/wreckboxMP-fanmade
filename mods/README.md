# Вселение в NPC — экспериментальный мод

Основная версия логики находится в `mods/possess-npc.js`. Она рассчитана на игровой адаптер `window.wreckboxModAPI`; сама по себе страница игры этот адаптер пока не экспортирует, поэтому подключение к реальному runtime требует совместимого bridge. В этой среде игру запустить и проверить нельзя.

## Управление в модуле

- **Стихия «Вселение»** — переключает режим выбора жителя (если адаптер предоставляет `registerElemental`).
- **Щелчок по жителю** — вселиться.
- **WASD / стрелки** — движение через штатный `moveCharacter`; житель поворачивается в направлении движения.
- **Shift** — бег.
- **Space** — запрос прыжка через штатный `jumpCharacter` или `requestJump`.
- **Esc** — выйти из тела.
- **E** — использовать объект под курсором.
- **F** — использовать ближайший доступный объект (например, сиденье/рабочий проп).
- **Q** — переключить связывание дверей; выбрать первую и вторую дверь, чтобы связать их.

## Последние изменения

- **Полностью удалён noclip**: нет клавиши его включения, полёта или отключения коллизий.
- **Убрано ручное изменение координат персонажа** как запасной способ ходьбы/прыжка. Движение теперь возможно только через API штатной физики игры; это предотвращает прохождение сквозь стены из-за прямого изменения позиции.
- **Не добавляются физические исправления жителя**: гравитация, столкновения, падение и регдолл остаются под управлением игры.
- Вместо большой обводки создан **маленький пульсирующий круг-маркер**. Для дверей позиция вычисляется из реальных границ объекта, маркер ставится около центра двери, а не ниже неё.
- Выделение двери для связывания синее; обычное наведение красное. Маркеры плавно исчезают при использовании объекта или завершении связывания.
- Поворот жителя следует направлению движения.
- Сохранены вызовы штатной интеракции и анимаций для сидения/работы через адаптер.

## Ограничения

Это изменения кода модуля, а не подтверждение полностью рабочего мода в самой Wreckbox. Игровой HTML содержит упакованный runtime, а совместимый `wreckboxModAPI` не обнаружен в исходной странице. Для фактического запуска нужно подключить адаптер к настоящим объектам NPC, камере, интерактивным объектам и штатному контроллеру движения. Без этого нельзя честно утверждать, что управление и переходы через двери уже работают в игре.
