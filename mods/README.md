# Вселение в NPC — экспериментальный мод

Файл логики: `mods/possess-npc.js`. Он работает через адаптер `window.wreckboxModAPI`. В текущем извлечённом `index.html` основной движок упакован/обфусцирован; полноценное подключение к реальным объектам игры и проверка в запущенной игре пока не подтверждены. Сам файл мода не меняет алгоритмы создания и поведения остальных NPC.

## Управление, предусмотренное модулем

- Иконка стихии «Вселяние» справа — переключение режима взаимодействия, если игровой адаптер предоставляет `registerElemental`.
- Щелчок по жителю — вселиться в него.
- **Esc** — выйти из тела, вернуть ИИ и HUD.
- **WASD / стрелки** — движение; NPC разворачивается по направлению движения.
- **Shift** — бег.
- **Space** — прыжок.
- **N** — включить/выключить ноуклип.
- **В ноуклипе:** WASD — полёт по горизонтали, Space — вверх, Shift — вниз.
- **E** — использовать подсвеченный объект.
- **F** — использовать ближайший стул/рабочий проп.
- **Q** — включить/выключить режим связывания дверей; щёлкните первую дверь, затем вторую.

## Изменения в последнем коммите

- Ноуклип явно отключает физику и коллизии через методы адаптера, затем включает их обратно при выключении.
- При падении WASD/стрелки больше не должны передаваться обработчику камеры; если адаптер умеет блокировать только клавиатурное управление камерой, используется этот более узкий переключатель.
- Добавлена обработка состояния падения по доступным методам адаптера и корректное восстановление предыдущего состояния ввода камеры.
- Гравитация больше не привязана к выдуманной плоскости `y = 0`: при отсутствии физического API используется движение вниз, а реальная обработка земли должна быть предоставлена игровым адаптером.
- Управляемый NPC получает уменьшенный множитель урона от столкновений; это работает только если движок реализует соответствующий метод адаптера.

## Ограничения

Это не проверенный релиз. В этой среде нельзя запустить Wreckbox и проверить настоящую физику, регдолл, дверные переходы, материалы/обводки или анимации. Для реального подключения игровой runtime должен предоставить `wreckboxModAPI` с настоящими объектами жителей, камерой, физикой, коллизиями, стихиями и интерактивными пропами. До этого изменения в модуле являются подготовленной логикой адаптера, а не гарантированно работающими функциями в игре.
